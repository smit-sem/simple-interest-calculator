# Simple Interest Calculator

A simple web-based application / script to calculate Simple Interest based on Principal amount, Rate of Interest, and Time period.

## Formula
$$\text{Simple Interest (SI)} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal Amount
- **R** = Annual Rate of Interest (%)
- **T** = Time Period (in years)

## Features
- Calculates total interest and total repayment amount.
- Simple, user-friendly interface / logic.

## Usage Example
- **Principal (P):** ₹10,000
- **Rate (R):** 5% per annum
- **Time (T):** 2 years
- **Simple Interest:** ₹1,000
- **Total Amount:** ₹11,000
